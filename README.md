# Ahmed Saeed Coaching Platform

A responsive online-coaching experience with a conversion-focused public site, package selection and payment flow, a private intake journey, and an admin interface for running the day-to-day client workflow.

## Highlights

- Responsive marketing site focused on trust, results and clear service packages
- Payment and intake pages that map the client journey after package selection
- Admin dashboard experience for client and program management
- Mobile-friendly visual system and Arabic-first content support
- Static front end built with HTML, CSS and JavaScript
